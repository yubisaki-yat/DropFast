# DropFast 🚀

> Ultra-fast cross-device P2P file sharing with QR code and OTP pairing, supporting up to 100GB direct streaming.

## Features

- ⚡ **Direct WebRTC P2P Transfer**: Fast browser-to-browser transfers without cloud storage limits.
- 📱 **QR & OTP Pairing**: Easy cross-device pairing between smartphones, tablets, and computers.
- 📦 **Large File Support**: Stream and transfer files up to 100GB directly.
- 🔒 **End-to-End Privacy**: Data is transmitted directly between peers.
- 🎨 **Modern Responsive UI**: Clean, intuitive interface for desktop and mobile devices.

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v16 or higher)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yubisaki-yat/DropFast.git
   cd DropFast
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the server:
   ```bash
   npm start
   ```

4. Open your browser and navigate to:
   ```
   http://localhost:3000
   ```
